# Public learning

Read the three Python courses and their examples without an account. The
**Computor: Public Courses** command opens the repository, clones it into
desktop VS Code, or starts a GitHub Codespace. Codespaces requires a GitHub
account and uses its quota. The public examples contain no instructor solutions.

Sign into Computor to join a course, keep progress, submit work, and ask Lena
through course messages. Lena gives hints and feedback; it cannot execute code.
The same extension supports the 26.10 and current Computor servers. Hosted
workspace capacity does not affect local VS Code or Codespaces.

Follow the [course guide](https://github.com/computor-org/data-science-python/blob/main/docs/GETTING_STARTED.md)
for the Python environment and course setup.

To ping Lena in course messages, type `@lena`, `@luna` or `@ai`, or choose
Lena from the `@` autocomplete dropdown. All three handles reach the same
tutor. This requires the matching backend update and its configured tutor
account; legacy `@luna` remains supported.
